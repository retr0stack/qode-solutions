# QODE SOLUTIONS — сайт

Маркетинговый сайт агентства цифровых решений. Next.js 15 (App Router),
TypeScript в strict-режиме, Tailwind CSS v4, без CMS: весь текст лежит
в типизированных файлах в `/content`.

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер |
| `npm run build` | Продакшен-сборка |
| `npm start` | Запуск собранного приложения |
| `npm run typecheck` | Проверка типов без сборки |
| `npm run lint` | ESLint |
| `npm run fonts:sync` | Перекладывает субсеты шрифтов из `node_modules` в `app/fonts` |

Служебная страница **`/design-system`** — живая документация токенов,
типографики, сетки и движения. В индекс не отдаётся (см. `app/robots.ts`).

| Что | Где |

| Переиспользуемые классы (сетка, градиентная рамка, сетка-фон) | `app/styles/utilities.css` |
| Геометрия знака Q | `components/brand/geometry.ts` |
| Сцены hero (сборка Q, градиент, наклон, посадка в шапку) | `components/hero/use*.ts` |
| Горизонтальная сцена процесса | `components/process/ProcessTrack.tsx` |
| og-картинка | `app/opengraph-image.tsx` |
| Метаданные страниц | `content/seo.ts` |
| Карта сайта | `app/sitemap.ts` |

Правило: цвет, размер или длительность не пишутся в компоненте. Сначала
токен в `tokens.css`, потом обращение к нему.

> **Добавили токен `--text-*` или `--color-*` — допишите его имя
> в `lib/cn.ts`.** tailwind-merge не знает про наш `@theme` и считает любое
> незнакомое `text-*` цветом текста: без записи в списке `FONT_SIZES`
> класс размера конфликтует с классом цвета, и один из них молча выбрасывается.

## Как устроены поверхности

Тёмная тема — не тема целиком, а **скоуп**. Любой блок с
`data-surface="dark"` переопределяет внутри себя семантические токены
(`--color-bg`, `--color-fg`, `--color-line`, кнопочные токены), а сами
компоненты про поверхность ничего не знают:

```tsx
<Section surface="dark">
  <Button>Обсудить проект</Button>   {/* сам станет вариантом для тёмного */}
</Section>
```

## Шрифты

В **Space Grotesk нет кириллицы** (только latin, latin-ext, vietnamese).
Поэтому дисплейная гарнитура собрана из двух файлов с разными
`unicode-range`: латиницу отдаёт Space Grotesk, кириллицу — Manrope
(близкая геометрия, схожие пропорции). Браузер выбирает файл по символу.
Текстовая гарнитура — Inter, латиница и кириллица.

Субсеты `*-ext` нужны только казахской локали (ә, ғ, қ, ң, ө, ү, һ) и
помечены `preload: false` — на русских страницах не грузятся.

Файлы лежат в `app/fonts`, коммитятся в репозиторий, источник —
пакеты `@fontsource-variable/*`. Обновить: `npm run fonts:sync`.

> **Про preload при сборке на Windows.** Next не создаёт
> `<link rel="preload">` для шрифтов: плагин `next-font-manifest` ищет в
> пути модуля подстроку `/next-font-loader/index.js?`, а на Windows в пути
> обратные слэши, поэтому манифест остаётся пустым. Файлы при этом
> помечены правильно (суффикс `-s.p.woff2`), и на Linux — в CI, Docker и
> на Vercel — preload появляется сам. Это не ошибка проекта.

## Доступность и производительность

- Контраст каждой пары «цвет на фоне» измерен, значения указаны на
  `/design-system`. Порог для текста — 4.5:1, для границ полей — 3:1.
  Яркие cyan и blue не проходят AA на белом, поэтому для текста и заливок
  есть затемнённые варианты (`--color-cyan-ink`, `--color-blue-ink`).
- Анимируются только `transform` и `opacity` — ни одно свойство не
  вызывает reflow.
- `prefers-reduced-motion`: компоненты движения рендерят контент сразу
  видимым, а не прячут его. Lenis и кастомный курсор не запускаются вовсе.
- Кастомный курсор и magnetic-эффект включаются только при
  `(hover: hover) and (pointer: fine)`.
- Первое, что получает фокус на любой странице — ссылка «Перейти
  к содержимому».

## Мультиязычность

`ru / kk / en` заложены структурно, сам i18n ещё не подключён: строк

## Сцены на GSAP

Две, обе на ScrollTrigger, обе считаются по фактическим замерам, а не
по магическим числам:

1. **Посадка Q в шапку** (`components/hero/useQDock.ts`). По скроллу знак
   уменьшается и уезжает в слот `[data-q-dock]` в шапке. Сдвиг и масштаб
   вычисляются из реальных позиций знака и слота и пересчитываются на каждом
   refresh, поэтому посадка точная на любой ширине. В конце пути едущий знак
   гаснет, а знак в шапке проявляется через `--header-mark-opacity`.
2. **Горизонтальный процесс** (`components/process/ProcessTrack.tsx`).
   От 1024px секция пинится и трек едет по скроллу; ниже — нативный скролл
   со snap. Разметка одна и та же, различается только поведение, поэтому
   при гидратации ничего не прыгает.

## Что проверено

Замерами в реальном браузере (не на глаз), на 360 / 768 / 1280 / 1920:

- горизонтального скролла нет ни на одной странице и ширине;
- знак Q садится в слот шапки пиксель в пиксель (`[48,24,32]` при 1280);
- один `<h1>` на страницу, у всех картинок есть `alt`, у всех полей —
  связанный `<label>`, у всех кнопок и ссылок — доступное имя;
- первый `Tab` попадает на «Перейти к содержимому», фокус видимый;
- при `prefers-reduced-motion` контент виден сразу, без остаточных
  `opacity: 0`; Lenis и кастомный курсор не запускаются;
- форма: пустая отправка даёт четыре сообщения валидации, корректная —
  состояние успеха, заявка уходит в `/api/lead` и пишется в лог сервера;
- в консоли нет ошибок при полной прокрутке всех страниц.
